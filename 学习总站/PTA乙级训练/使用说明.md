# PTA 乙级训练 · 使用说明（从 0 开始）

一个**从 0 一步步带你到 PTA 乙级水平**的 C 语言训练网站：**讲解 + 练习 + 在线运行 + 自动判题 + 错题本**。打开 `index.html` 即用（联网可在线运行）。

## 一、PTA 乙级是什么
- 浙大「拼题A」(PAT) 的**基础级(Basic Level)**，题号约 **1001~1095**，难度≈本科《C 语言 + 简单算法》。
- 常考类型：**输入输出/格式化、数学(素数·最大公约数·进制)、字符串处理、数组/排序/查找、简单模拟**。
- **平台**：`pintia.cn`（拼题A）→ 题库 → 乙级，从 1001 顺序做。
- **目标**：把 **1001~1050 做熟**，乙级就稳了。

## 二、学习路线（本课程按顺序排好）
| 步骤 | 章节 | 内容 |
| --- | --- | --- |
| 开始 | 开始这里 | PTA 乙级介绍 + 练习方法 + 路线 |
| 第 1 步 | 输入输出 | 第一个程序 & A+B、多组输入到 EOF、读含空格的整行 |
| 第 2 步 | 数学与进制 | 判断素数、求和与阶乘(long long)、gcd/lcm、进制转换 |
| 第 3 步 | 字符串 | 字符分类统计、回文判断、单词反转(说反话) |
| 第 4 步 | 数组·排序·查找 | 数组统计、qsort 用法、二分查找 |
| 第 5 步 | 综合模拟 | 成绩排名(结构体+排序)、日期计算(闰年/第几天) |

**按顺序**一节节做，每节课都：看讲解 → 参考代码 → 在**代码框**自己敲 → **▶运行并判题** 对答案。

## 三、界面怎么用
- 顶部切**章节** → 点**知识点**。
- 左栏：📖讲解、💡要点/易错、📄参考代码。
- 右栏：选语言 → 改代码 → **📥标准输入**填数据 → **▶运行并判题** → **📤运行输出** + **✅通过/❌不通过**（自动对比期望输出）→ **🎯期望输出**对答案 → **↺恢复参考代码**。
- **❌错题本**：判题没过的题自动收录，点它重练；做对自动移出。
- **⏱限时模拟**：1.5h 计时 + 随机 3 题，交卷看通过数。
- 运行走公开在线编译 **Wandbox**，需联网；繁忙自动重试。

## 四、自己加题
编辑 `lessons.js`，照格式加对象：
```js
{ id:"s16", chapter:"第5步 · 综合模拟", title:"…", lang:"c",
  teach:"讲解…", points:"要点…",
  code:'#include <stdio.h>\n…',
  stdin:"输入示例\n", output:"期望输出\n" }
```
（`chapter` 用文件名分组；`stdin`/`output` 就是判题标准。）
