# 上机实战网站 · 使用说明

**知识点讲解 + 参考代码 + 自己敲代码·在线运行（输入/输出）** 的上机练习网站。**打开 `index.html` 即可用**（需联网才能“在线运行”）。

## 一、界面怎么用
- 顶部切 **章节** → 下面点 **知识点**。
- **左栏**：📖 讲解、💡要点/易错、📄 参考代码。
- **右栏（自己敲代码）**：
  1. 选语言（**C / C++ / Python**，默认按课程）
  2. **代码框**：已预填参考代码，**可以随便改**
  3. **📥 标准输入**：程序要读的数据写这里（如 `3 5`）
  4. 点 **▶ 运行**
- **📤 运行输出**：显示结果（stdout / 编译错误 / 运行信息）
- **🎯 期望输出**：对照标准答案
- **↺ 恢复参考代码**：改乱了点它还原

## 二、在线运行是怎么实现的
点“运行”时，代码会发到公开的在线编译**服务 Wandbox**（`wandbox.org`）编译执行，再把结果取回来显示——所以**要联网**。
- 首次运行可能几秒；服务偶发繁忙会自动**重试一次**。
- 完全离线时跑不了：把代码复制到你本地的 **Dev-C++ / VS Code / 在线 IDE** 运行即可（讲解和参考代码不受影响）。

## 三、覆盖内容（36 节）
- **从0开始**：0 基础怎么开始
- **C 基础**：变量与类型、运算符、分支、循环、函数、一维/二维数组、字符串、指针、指针与数组、结构体、递归、常见错误与调试
- **C 语言速复习**：输入输出、数组与循环、指针与 malloc、结构体
- **数据结构上机**：顺序表(增删/按值删除)、单链表、双链表、链式栈、循环队列、链式队列、栈(括号匹配)、二叉树(建树+中序/叶子/深度/层序)、图 DFS/BFS、邻接表、冒泡/选择/插入/快排/归并、二分查找、哈希表

每节都是**可直接运行的完整 C 代码**，并给出**示例输入 → 期望输出**。

## 四、自己加课
打开 `lessons.js`，往数组里加对象：
```js
{ id:"ds9", chapter:"数据结构上机", title:"图的 Dijkstra", lang:"c",
  teach:"讲解……",
  points:"要点/易错……",
  code:'#include <stdio.h>\n...（用 \\n 换行）',
  stdin:"输入示例\n",
  output:"期望输出\n" }
```
| 字段 | 说明 |
| --- | --- |
| chapter | 章节（顶部标签） |
| title | 知识点标题 |
| lang | `c` / `cpp` / `python` |
| teach / points | 讲解 / 要点 |
| code | 参考代码（会被预填到编辑器） |
| stdin / output | 示例输入 / 期望输出 |

## 六、上线给同学用
把 `上机实战` 整个文件夹拖到 **Cloudflare Pages**（免实名）或传 Gitee / GitHub，得到网址即可，手机也能用。
> 注意：在线运行依赖外部服务，若你的网络访问不了 wandbox 会自动提示；教学内容和参考代码始终可用。
