# 408 学习网站 · 使用说明

**离线学习网站**：按「科目 → 章节 → 知识点」浏览，每节都有 **📖讲解 + ⚙️运行原理 + ✏️例题（先自己做，再点选项判对错看解析）**，可 **标记学会**、按关键词 **搜索**、看 **进度**。

## 一、怎么用
- **双击 `index.html`** 用浏览器打开（电脑/手机都行，完全离线）。
- 顶部切 **科目** → 下面按 **章节** 列知识点 → 点一个看内容。
- 每节结构：讲解 → 运行原理 → 例题（点选项即判对错、显示解析；有的知识点有**多道例题**）。
- **标记学会**、**上一节/下一节**；右上角「已学会 x/总数」（存本机）。
- 顶部 **搜索框**：输入 `页面置换`、`Cache`、`TCP`、`哈夫曼` 等快速定位。

## 三、怎么加内容（数据文件，4 个）
内容拆在多个文件里（`data-ds/co/os/cn.js` 为各科主文件，`data-extra.js` 为补充），建议加在对应科目文件：
- 数据结构 → `data-ds.js`
- 计算机组成原理 → `data-co.js`
- 操作系统 → `data-os.js`
- 计算机网络 → `data-cn.js`

格式（往数组里加对象）：
```js
{ subject:"数据结构", chapter:"排序", title:"快速排序",
  teach:"讲解文字……",
  principle:"运行原理……",
  examples:[
    { q:"题干……", options:["A选项","B选项","C选项","D选项"], answer:"C", explain:"解析……" },
    { q:"第二道例题……", options:["…","…","…","…"], answer:"A", explain:"……" }
  ] }
```

| 字段 | 说明 |
| --- | --- |
| subject | 科目（顶部标签） |
| chapter | 章节（分组） |
| title | 知识点标题 |
| teach | 讲解 |
| principle | 运行原理 |
| examples | 例题数组：每题含 q 题干、options(A/B/C/D)、answer 正确字母、explain 解析 |
