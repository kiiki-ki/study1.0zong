# 一站式学习总站 · 使用说明

把三个学习网站合到**一个入口**：顶部五个标签 **🏠 首页 / 📘 408 知识点 / 💻 上机实战 / 🎯 PTA 乙级 / 🗂 学习指南**，点一下就切换。打开 `index.html` 即用。

**🏠 首页（仪表盘）**：显示三模块进度条（408 已学会 · 上机实战已通过 · PTA已通过，含错题数）、**今日学习建议**、**今日目标打勾清单**，并可一键跳转各模块。
> 进度取自浏览器本地存储：**用托管网址打开时**三模块与首页共享进度；若本地直接双击、数字显示为 0，请用托管后的网址打开。

## 目录结构
```
学习总站/
├── index.html            ← 总入口（顶部标签切换）
├── guide.html            ← 学习指南
├── 408学习/              ← 模块1：408 四门课知识点
├── 上机实战/             ← 模块2：0基础 C/数据结构 上机
└── PTA乙级训练/          ← 模块3：PTA 乙级循序课程
```
（三个子文件夹就是原来的三个网站，功能完全不变。）

## 三个模块各是什么
| 标签 | 内容 | 特色 |
| --- | --- | --- |
| 📘 408 知识点 | 数据结构45/计组45/操作系统35/计网25，**100 个知识点** | 讲解+原理+例题、搜索、标记学会、**问问题** |
| 💻 上机实战 | 0 基础 **36 节课**（C 基础 → 数据结构） | 在线编辑器+输入+运行+**判题**、错题本、限时模拟 |
| 🎯 PTA 乙级 | 循序 **16 节 + 1001~1050 刷题清单** | 在线运行+判题 |

## 怎么用
- **双击 `学习总站/index.html`** 用浏览器打开（手机也行）。
- 顶部点标签切模块；各模块进度存在本机浏览器（关掉也在）。
- 在线运行需联网（走公开编译服务 Wandbox）。

## 上线（可选）
把 **`学习总站` 整个文件夹**拖到 **Cloudflare Pages**（免实名）或传 Gitee/GitHub，得到网址，手机加到主屏幕即可。
> 注意：要传**整个文件夹**（含三个子文件夹），否则内嵌的模块会 404。
